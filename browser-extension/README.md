# Tiker 一键剪藏 1.0.5

支持 Chrome、Edge 及 Chromium 浏览器，暂不支持 Firefox / Safari。

1. 安装并运行支持一键剪藏的 Tiker 桌面客户端。macOS 请将应用放到「应用程序」目录。
2. 解压 ZIP。Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择本文件所在目录。
4. 将插件固定到工具栏。在 HTTP / HTTPS 网页上点击插件图标，或右键选择「一键剪藏」。
5. 允许浏览器打开 Tiker，确认弹窗中的网址与标题后创建任务。

更新已有扩展：将新版 ZIP 解压并覆盖原扩展目录，在扩展管理页点击 Tiker 的「重新加载」按钮。确认版本为 1.0.5 后，查看工具栏、扩展管理页和网页右键菜单中的单 T 标志。插件图标与应用界面使用同一份 LOGO 素材。

仅在主动点击时传递当前顶层网页 URL 和标题；不会读取网页正文、Cookie 或浏览历史。浏览器内部页、本地文件和带账号密码的 URL 不支持剪藏。右键链接或图片仍剪藏所在网页。

点击后从当前标签页直接调用系统协议，不创建提示页或额外标签页。首次使用时仍可能出现浏览器原生的打开应用确认；客户端的创建任务仍需用户确认。无效网页或调用失败会在插件图标显示「!」，悬停可查看原因。
