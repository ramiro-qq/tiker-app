# 配图妙手

配好一张文章配图，本质是"把文字的气味翻译成画面的形状"。让读者在点开之前，就被一张对味的图抓住。

## 〇、输入来源与内容读取（先弄清"配什么"）

用户给的信息可能是三类，先把它变成"可读懂的主题"，再往下配图：

1. **直接文字/一句话/一段话**：直接用，跳到"先做的三件事"。
2. **上传的文档（Word/PDF/TXT/Markdown/图文排版等）**：用可读取文档内容的工具解析文本与图片（注意图文文档里可能本来就带配图，可作为风格/内容的参考，但不要默认为成品图直接复用或交付）；从正文提炼主题、调性、金句与小标题。
3. **文章链接/图文网页（公众号、头条/百家号、新闻、知乎、博客等）**：先打开该链接读取正文内容。读取时注意：
   - 优先获取**正文全文**（标题、小标题、段落、图片 alt 与位置），而不是只看摘要；拿不到正文时如实说明，不要凭链接标题臆测配图，也不要把访问失败的链接当搜索词去猜内容。
   - 正文里已配的图可作为该篇文章**既有风格/版面参考**，但直接用于新配图前要确认来源与版权；默认应当为文章生成/搜索独立的配图，而不是搬运页面上已有图片。
   - 如链接需要登录或有访问限制读不了，先退回让用户补充文字摘要或贴正文，不绕过授权。

读到内容或确定读不到后，再进入下一步。一句话：**先确保真正"看懂"了要给什么配图，再动手。**

## 一、先做的三件事（动手配图前必读）

1. **听懂主题**：把用户给的一段话/一篇文章/一个文档主题，压缩成一句话内核（讲了什么、什么情绪、什么调性）。
2. **拆出意象**：从这句话里抽出 1~3 个可画/可搜的"具体意象"，而不是抽象概念（"团队协作"→"握手/拼图/并肩行走"；"焦虑"→"深夜台灯/咖啡/手表"）。
3. **锁定平台**：确认图片要发到哪个平台、用于哪个位置（封面/头图/内文/长图）。位置不同，规格不同——先翻 `references/platform-specs.md` 查规格表，不要凭空猜尺寸。

## 二、三条路径的选择（核心决策）

用户没指明时，按下面规则自动选择，拿到图后始终复核"是否贴主题、是否清晰、是否合规"：

| 路径 | 什么时候走 | 怎么做 |
|---|---|---|
| **① 配图搜索** | 有明确意象、需要真实/现成素材、想参考网络图库、或用户说"搜一下图" | 用联网搜索/搜图能力以提炼出的关键词（中英各一组）检索；从结果里挑主题贴、构图干净、可用性高的候选；**明确标注来源与是否可商用**（见"红线"） |
| **② 修改优化** | 用户已有图片，但不够清晰 / 比例不对 / 想抠图 / 想统一风格 / 想去掉多余元素 | 先用"变清晰"提画质；再按目标平台"改比例"（裁切或补边）；需要主体时"抠图"换背景；多张图统一色调/风格用二次生成或风格化 |
| **③ AI生成** | 意象太抽象、需要原创画面、没有现成图、用户明确要"生成一张图" | 按 `references/prompt-kit.md` 的模板构造提示词（主体+场景+风格+光线+构图+负面），再按目标平台选比例与分辨率生成；可生成候选略多一张让用户挑 |
| **④ 纯排版兜底** | 搜图与生图都不合适（版权敏感不敢用 / 生图跑题 / 金句·数据·清单类内容本就适合排版） | **色块 + 大字**直接排版：按情绪取 **1 主色 + 1 辅色**（见"风格与情绪"配色表），层级 ≤3（大字标题 / 小字副题 / 角标），比例按平台规格表，亮底配深字、深底配白字 |

> 多路径可组合：搜到好图但比例不对 → ②改比例；生成示意图太素 → 叠加画面元素再生成；整套还差一两张 → ④排版卡补齐。交给用户前，**说明你走了哪条路、为什么**。

### 搜图候选的硬判定（走路径①时逐张过，任一硬伤即弃）

| 项 | 通过标准 |
|---|---|
| 相关性 | 画面主体与意象描述一致，不是纯装饰图 |
| 分辨率 | 宽 ≥800px（封面/头图建议 ≥1080px） |
| 清晰度 | 主体清晰，无明显压缩噪点、无截图感 |
| 水印 | 无水印、无二维码、无第三方 logo 横幅 |
| 版权 | 来源可标注（官方通稿 / 明确免版权图库 / 来源链接） |

## 三、平台适配（这是"适合发布"的关键）

动手选比例/尺寸前，先读 `references/platform-specs.md` 的平台规格表。核心原则：

- **封面/头图**：平台裁切严格，比例务必按表给对（如公众号头图 900×383、小红书封面 3:4、头条/百家号 16:9），主体放**安全区内**，别让重要内容落在裁切边缘。
- **内文配图**：宽图优先横向（16:9 / 4:3），文字少的地方用图，避免和正文叠字冲突。
- **竖版平台**（小红书/抖音等）优先 3:4 或 9:16；横版平台（知乎/头条/公众号正文）优先 16:9。
- 拿不准时给 1:1 方形兜底 + 提示每种平台推荐值。

## 四、风格与情绪（决定"对味"）

- **紧贴内容调性**：干货/专业文 → 干净、留白、几何感；情感/故事文 → 暖色调、有温度、生活化；新闻/热点 → 冲击力、对比强；科技/未来 → 冷色调、高清、科技感。
- **整篇统一（量化规则）**：一篇文章的多张配图，开工前先按内容情绪从下表定 **1 主色 + 1 辅色**，全组共用，不许每张各配各的：

| 内容情绪 / 领域 | 主色 | 辅色 |
|---|---|---|
| 科技 / 互联网 / AI | #1F4E79 深蓝 | #E8A33D 暖橙 |
| 财经 / 商业 | #14352E 墨绿 | #C9A96A 金 |
| 生活 / 情感 / 治愈 | #F5EDE0 米白 | #D97848 珊瑚 |
| 质量 / 制造 / 专业 | #37474F 石板灰 | #4FC3F7 天蓝 |
| 历史 / 文化 | #F0E6D2 宣纸色 | #8B3A2E 绛红 |
| 热点 / 事件 | #212121 近黑 | #FFD54F 亮黄 |

- **避免"AI味过重"的通用图**：少用一眼假的渐变光效、过度饱和、无意义装饰；优先具体、有信息量的画面。

## 五、红线（配图必守）

- **来源读取**：读了文章链接/图文文档来配图，交付时说明读取来源；读取失败或有访问限制时如实告知，不猜测内容、不绕过登录/授权。
- **版权**：搜索来的图，交付时必须标注来源（链接/图库名）；默认不承诺"可商用"，除非能确认是免版权图库（如明确标注 CC0 / 免版权）。**禁止把带水印的图当成品交付。** 文章页面上已存在的配图，未经确认不得当作成品直接交付。
- **合规**：不生成/不使用违反法律法规、公序良俗、侵犯肖像权与商标权的内容；涉及真人、品牌 logo、名人时尤其谨慎。
- **准确**：新闻/数据类配图不能"看图说话"误导；配图信息要与文字一致，不夸大不改事实。
- **隐私**：用户上传的私密文档、或受限链接内容，仅用于本次配图，不外传不留存。

## 六、交付方式

- 给用户**成品图**（用可访问的路径/链接），并附一句说明：这张图用于哪个平台哪个位置、走的哪条路径、来源（如果是搜索来的）。
- 一次给 1~3 张候选即可，别堆一屏；说明每张的差异（如"A 更学术 B 更活泼"）。
- 如果用户要"一篇文章整套配图"（封面+2~3 张内文），按"先定整体风格 → 逐张配 → 最后统一校验尺寸比例"的顺序交付，并附**一张交付清单**（每张一行：用途位置 / 尺寸比例 / 来源与版权提示），方便用户逐张确认与留档。

## 七、执行流程（一句话版）

**弄清输入（文字/文档/链接，先读懂） → 听懂主题 → 拆出意象 → 定平台 → 选路径（搜/改/生/排版兜底）→ 按规格适配 → 过红线 → 交付。**

## 依赖与工具

- 联网搜索（搜图/查证来源）、图片生成（生图/编辑）、图片增强（变清晰/抠图/改比例）等能力按需调用；本技能自身不依赖第三方外部 API。
