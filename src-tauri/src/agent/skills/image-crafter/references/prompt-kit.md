# 关键词提炼 & 生图提示词工具箱

配图三步的核心是"把文字翻译成可搜、可画的语言"。本文件给两条生产线：**搜索提示词** 与 **AI 生图提示词**。

---

## 一、从文字到"搜索关键词"

给搜索 / 生图用的关键词，不是抄原文，而是"压缩成意象"。

### 步骤：主题 → 意象 → 关键词

1. **压缩主题**：这句话/文章到底在讲什么？用一句话说清（例："劝年轻人不要内耗"）。
2. **抽意象**：找 1~3 个"具体能看见的东西"，不要抽象词（"内耗"→"深夜书桌/一团乱麻/一盏孤灯"）。
3. **写关键词**：中文一组 + 英文一组（图库/国外引擎英文命中率高），每组 2~4 个词，用空格或"+"连接。

### 关键词构成块（可自由组合）

- **主体块**：who/what（"中年男人""办公桌""雨夜街道"）
- **动作/状态块**：doing/being（"低头思考""独自加班""灯下工作"）
- **场景块**：where（"深夜办公室""窗边""城市夜景"）
- **风格块**：style（"写实摄影""极简插画""复古胶片""科技感"）
- **光线/情绪块**：light/mood（"暖黄台灯""冷蓝调""柔和自然光"）
- **构图块**：composition（"居中构图""大留白""特写""背景虚化"）

### 例子

| 原文 | 压缩主题 | 搜/生图关键词 |
|---|---|---|
| "别再为打翻的牛奶哭泣" | 放下过去、向前看 | 中文：打翻的牛奶 向前走 阳光 早餐桌 / 英文：spilled milk sunlit breakfast forward |
| "AI 时代普通人的机会" | 人机协作、升维 | 中文：人与机器人 协作 蓝色科技感 城市 / 英文：human robot collaboration blue futuristic |
| "深夜加班的年轻人" | 城市打工人 | 中文：深夜 玻璃幕墙 一个人 电脑 城市灯光 / 英文：late night office lone worker city lights |

## 二、AI 生图提示词模板

### 通用公式

> **[主体]**，**[动作/状态]**，**[场景]**，**[风格]**，**[光线 + 情绪]**，**[构图]**，**[负面排除]**，**[画质词]**

按需要取舍模块，不必全塞；硬约束（人要什么、不要什么）优先保留。

### 完整示例

```
一位戴着眼镜的青年男性，坐在深夜书桌前低头写作，
桌上散落纸张与一杯咖啡，
写实摄影风格，暖黄台灯，安静专注的氛围，
中景构图，前景略微虚化，
（不要：模糊、变形、多余文字、水印）
高清，细节丰富
```

### 各风格一句话底稿（可直接套主体）

- **极简插画**：扁平色块，大留白，几何构图，低饱和
- **摄影写实**：真实质感，自然光，浅景深，细节纹理
- **商务科技**：冷蓝/深灰主调，光效，网格线，干净界面
- **暖情故事**：暖色调，柔光，生活化细节，胶片颗粒
- **新闻冲击**：高对比，强主体，广角，动态感
- **国风/古意**：水墨，留白，宣纸质感，淡雅

### 负面排除（负面提示词，常用集合）

> 模糊、低清、变形、多余手指、多余肢体、文字错乱、水印、logo、边框、过度饱和、杂乱背景、恐怖元素

### 画质词

> 高清、高分辨率、细节丰富、锐利；需要放大场景时加"大尺寸、可用于放大输出"。

## 三、生成/搜索前的自检三问

1. 关键词里有没有"具体可见的意象"？（纯抽象词要拆）
2. 中文英文各一组了吗？（提高命中）
3. 目标平台的比例、风格确定了吗？（决定选图/生成参数）

---

## 四、修改优化的常用指令

对已有图片做处理时，把需求讲清楚再动手：

- **变清晰**：直接提"提高清晰度、去噪、锐化"。
- **改比例**：说清目标比例（如"改成 16:9，裁切时保留居中主体，别切掉文字"）。
- **抠图换背景**：说清要抠的主体 + 新背景（"把人物抠出来，换成干净的渐变背景"）。
- **统一风格**：给参考基调（"所有配图统一成暖色写实风，用同一色系"）。
- **去元素**：说清要去掉什么（"去掉 logo / 水印 / 背景里的杂物"）。

> 提示：修改时把"要保留什么、要去掉什么、裁切安全区在哪"说具体，比一句"好看点"可靠得多。
