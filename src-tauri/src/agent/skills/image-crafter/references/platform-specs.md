# 媒体平台配图规格速查表

> 封面/头图裁切最严，主体务必放安全区。下表为常用推荐值，**以平台后台实时指引为准**，需要精确时别再直接编。

## 一、公众号（微信）

| 位置 | 推荐尺寸 | 比例 | 说明 |
|---|---|---|---|
| 头条封面（首图） | 900 × 383 | 2.35:1 | 列表页/分享卡显示，最严 |
| 次条及以下封面 | 900 × 500 | 9:5 | |
| 正文顶部大图 | 900 × 500（或 900×450） | 9:5 / 2:1 | 正文宽约 900px，配图建议 ≤ 900px 宽 |
| 正文内插图 | 900 × 506（或 1:1） | 16:9 / 1:1 | 居中，别超 900 宽 |
| 引导关注/关注后回复图 | 尺寸自由 | — | 方形常用 |
| 分享小图 | 自动裁切 | — | 主体靠中间 |

要点：正文插图宽度控制在 900px 内；封面主体居中上方，避免被系统裁掉标题前两个字。

|---|---|---|---|

| 二图及后续 | 1080 × 1440 | 3:4 | 同比例保持连贯 |
| 长图 | 宽 1080，高不超 5400 | — | 单图可较长，注意压缩画质 |

要点：小红书面包一贯竖版 3:4；封面常叠加标题文字，主体构图预留文字区（上方或下方留白）。

| 视频封面 | 1080 × 1920 | 9:16 | 竖版视频 |

| 位置 | 推荐尺寸 | 比例 | 说明 |
|---|---|---|---|
| 视频封面 | 1280 × 720 | 16:9 | B站/YouTube 一致 |
| 封面文字区 | 右下为主 | — | 预留字幕不被遮挡 |
| 专栏封面 | 16:9 | 16:9 | |

要点：封面 16:9 固定；标题文字放右下、主体放左侧安全区。

## 八、通用兜底

- **不确定平台**：给 1:1 方形 + 16:9 横向各一张，说明对应偏好。
- **横竖都能用**：4:3 是折中。
- **清晰度**：正文/封面建议至少 1080px 宽；要放大的场合用 2K/4K（生图时按需求选分辨率）。
- **压缩**：交付前确认画质够（避免过度压缩起噪点）。

## 手动改比例的通用做法

1. 先"变清晰"提画质；
2. 按目标比例"改尺寸"：裁主体 → 保安全区；构图被裁走关键部分时，用"外扩补边"（AI 扩展边缘）而非硬拉变形；
3. 多张图统一宽高比后交付。
