# 安装与入门

## 安装

从项目 [Releases](https://github.com/ramiro-qq/tiker-app/releases) 选择与你的系统及 CPU 架构一致的附件。若没有对应附件，可按 [开发指南](../CONTRIBUTING.md) 从源码构建。发行状态、签名与平台验证以每次版本记录为准。

macOS 使用 DMG / App，Windows 使用安装包，Linux 使用 AppImage / deb。当前不提供自动更新；不要把历史构建验证当作新安装包已验收的证据。

## 第一次使用

1. 启动桌面应用，在设置中确认资料库位置。首次默认位于系统文稿目录的 `tiker`；资料库包含隐藏元数据，请整体备份。
2. 在「文档」创建文档或导入本地文件，使用搜索定位资料。
3. 在「设置 → 模型配置」填写接口、模型 ID 和密钥，点击确认并测试。探知需要已配置的自定义 OpenAI 兼容模型；剪藏使用默认模型。
4. 进入「探知」，在输入框底部选择当前模型并提交需求，检查来源与生成材料后再归档。
5. 从侧栏底部「插件」进入现有插件页面，下载并安装 Chrome / Edge 扩展。先启动桌面应用，再通过扩展或网页右键创建剪藏任务。详细步骤见 [插件指南](browser-clipper.md)。

## 可选 GitHub 同步

在「设置 → 同步与备份」连接 GitHub，在系统浏览器批准设备码，选择目标仓库。建议使用专用私有仓库；绑定后先预览，再明确启用同步。账号连接成功不等于已经上传内容。冲突及恢复见 [内容同步](github-content-sync.md)。

## 常见问题

- **浏览器预览不能保存或调用模型**：请使用 `npm run tauri dev` 启动桌面版；浏览器仅用于界面预览。
- **旧模型提示缺少 API Key**：在模型配置中编辑并重新输入；应用不再读取旧模型钥匙串。
- **GitHub 授权失效**：重新走设备码授权。解除本机连接不会删除远端资料，也不会撤销 GitHub 网站上的 OAuth 授权。
- **迁移电脑后附件无法打开**：旧授权引用的是原设备路径，需要在新设备重新选择文件；参考 [备份范围](storage-layout.md)。
- **剪藏或探知失败**：检查模型连接、服务商限制和来源网站可用性；提交问题时只附脱敏错误，不上传本机配置文件。
