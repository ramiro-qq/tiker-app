## 导出与展示边界

- 使用 Pencil 原生 Export，1× 尺寸、WebP 质量 92；单张约 32–75 KiB，总计约 357 KiB，点击原图可查看细节。
- 探知三张图通过临时副本导出，将原有模型名称统一为“自定义模型（示例）”；临时副本在导出后删除，未更改原画板。
- 检查过导出画板的文字，展示的是示例文章、主题、链接和教学内容，不含运行凭据、私人资料或本机绝对路径。
- 图片是设计稿，不是当前版本的实机功能验收证据。示例耗时、来源数量及任务数量不能用作性能或效果承诺。
- 部分画板保留历史状态：侧栏未画出当前必须保留的插件入口；首页卡片分类、搜索提示与进度文案可能和当前界面不同；实践图中的 `参考来源.md` 是旧展示文案，当前实现会将参考来源追加到材料正文，而非固定生成独立来源文件。
- 当前侧栏固定为图标状态，顺序为「搜索 → 探知 → 收藏 → 文档」，底部保留「插件」和「设置」；探知使用用户配置的真实自定义模型，不内置截图中的模拟选择。
- 更新图片时重新核查文字、账号、模型名称、URL 参数、文件路径及正文隐私。仅将明确用于公开展示的图片放入本目录，不迁入整个本地截图目录。
