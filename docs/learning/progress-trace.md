# 探知实时过程记录

每个主题识别、资料研究和材料生成请求都有独立的 Tauri Channel。后端在真实操作前后报告状态：入口读取、下钻、三组检索、正文读取和跳过、大纲规划、资料缺口、材料输出和校验。模型只汇报公开输出的接收量，最终主题和学习大纲作为工作摘要；不显示 reasoning_content 等私有推理字段，也不编造百分比或已完成的工作。

前端按本轮请求标识归并步骤，同一步骤更新原记录。时间线显示总耗时与步骤耗时；等待期间显示最近更新距离，不伪装心跳为新进展。默认显示最近四步，可展开全部或收起整条记录。正常完成后默认收起，失败和停止保留详情。当前步骤在用户停留底部时跟随更新；用户滚动查看旧步骤后不会被拉回。初次研究与已有材料的追问都显示进度。

停止、删除、切换资料库和组件卸载仍由原有取消机制处理，迟到的事件不能更新新请求。运行记录只保留在当前应用会话，不写入同步会话或教材，也不在重启后伪装成仍在进行。

交互参考 [shadcn AI Elements](https://ui.shadcn.com/docs/ai-elements) 的 Trace/Marker 结构，复用现有 React、lucide 和项目 CSS；没有给现有项目引入整套 Tailwind 配置。焦点以控件背景和文字颜色表示，不引入 outline 或焦点阴影。

## 验证范围

- Rust：真实本地 HTTP 响应验证 SSE、UTF-8 拆分、私有推理字段过滤、输出截断和连接中断；现有后端回归。
- Node：步骤合并、结束状态冻结、迟到事件、请求取消及 channel 分配；现有学习会话回归。
- 浏览器：隔离 IPC 数据驱动正常、停止、迟到回包、失败和已有文档追问，验证折叠、键盘操作、自动跟随、1180/980 窗口和计算焦点样式。测试模型和测试教材仅存在于隔离浏览器，不作为真实模型效果证据。
- 构建与 check:focus-styles。
