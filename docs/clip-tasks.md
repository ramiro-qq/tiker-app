# 网页剪藏收藏记录

剪藏保存网页链接、归档类目、标题、简介、标签，以及任务状态和时间等管理信息。编辑结果支持本地草稿；新任务只整理标题、简介、目录、标签，不传送完整 DOM 或文章正文，不新增正文缓存，也不生成资料库文档。兼容保留旧记录的正文和笔记字段供搜索，不新增笔记编辑流程。

## 使用

1. 「新建剪藏」输入链接，可选填写剪藏要求。
   创建时在后端统一去重：当前资料库已收藏的链接提示「该网页已收藏，请勿重复收藏。」；排队中、提取中或待确认的同链接提示已有收藏任务，不再重复创建。手动新建和浏览器插件使用同一校验入口。比较链接时统一域名大小写、默认端口等 URL 格式并忽略 `#` 锚点，保留协议、路径及查询参数；失败或已取消的任务允许重新创建。去重与写入在同一存储锁内完成。
2. 在「剪藏任务」查看进度，使用「全部」「待确认」「失败」筛选。任务使用自适应多列卡片，窄屏显示单列。卡片展示标题、链接、摘要或异常原因，内容标签使用小字号并依次轮换浅色背景；底部左侧显示状态，右侧为紧凑的默认文字色操作按钮，不展示时间或分隔横线。所有任务均可删除或刷新重新剪藏，待确认和失败任务额外提供编辑入口。刷新保持任务位置和原内容，清除旧错误，提取成功后用新结果替换并清除旧编辑草稿；删除需确认。已归档和已取消记录不在任务列表展示；标题左侧箭头返回收藏列表。
3. 「编辑并确认」核对类目、标题、简介和标签，失败任务可通过「手动编辑并添加」补充后直接收藏，无需再次调用模型。修改自动保存草稿；取消后重开恢复草稿。标题和类目必填，简介和标签可选，确认后归档并清除草稿及失败原因。移动目录独立保存，不覆盖其他字段和编辑草稿。
4. 收藏详情展示链接和收藏信息，编辑和删除使用默认颜色的图标按钮，悬停或键盘聚焦显示操作提示；末尾带背景底色的「打开网页 →」和原链接均直接通过系统浏览器打开当前网页。
5. 「批量校正」重新抓取网页并调用所选模型生成总结，仅更新总结字段；失败保留原内容。进度弹框使用主题色进度条，右下角提供「取消」和「后台继续」；取消会中断当前提取并停止后续校正，已完成的结果保留，未完成的剪藏保持原内容。顶部按钮固定显示「批量校正」，后台执行时仍可点击重新查看进度。支持失败重试、结果重新打开、再次校正全部、单条或批量删除，删除需要二次确认。

## 模型

统一在「设置 → 模型配置」配置 Provider、Base URL、模型 ID 和 API Key，剪藏使用默认模型。密钥保存在系统钥匙串。剪藏页「剪藏设置」可通过「提取模型」选择设置中添加的模型，或跟随默认模型，并在「通用要求描述」中保存整理偏好。配置保存在 `clips.json` 的 `settings` 中，用于之后开始的提取和重试；单次剪藏要求优先，结构约束始终保留。选择的模型被删除时要求重新选择，不静默切换。

自动提取调用 AI 整理。未配置默认模型、网页请求失败或模型结果不合格时，任务会失败并显示原因，配置或修正后可重试，也可手动编辑并收藏；不会把网页元信息直接当作 AI 结果。仅将网页标题、描述、关键词、链接、已有类目和整理要求提供给模型。无网页描述时，仅读取最多 160 字的短摘录作为简介参考；不构建或传送完整正文/DOM 上下文，不把网页文本写入 content。只有已归档内容参与列表搜索。

AI 生成校验：标题非空、用途简介为 1–50 字、标签为 1–3 个非空且去重的关键词。类目为 1–3 级目录，用 `/` 分隔，每级最多 40 字，不能使用「待整理」占位类目。AI 结果不合格时自动请求修正一次，仍不合格则标记失败。

自动归档通常组织为“领域目录 / 用途目录 / 功能类别目录 / 剪藏标题”，前三层写入 category，第四层为 title，不额外创建标题目录。分类粒度使用可容纳多个同类收藏的稳定功能类别，避免空泛兜底类目和按产品、版本、单篇标题或单个功能点建类。同义目录沿用已有名称，只有无法准确承接时才新建。AI 先判断当前页面的主题和实际用途，再比较已有类目的完整路径；仅在主题、用途均一致时复用。托管平台不决定内容分类：GitHub 上的文档框架源码、AI 教程与代码托管服务分别处理。现有父级合适而子级不合适时可新建子级，没有合适父级时可新建路径。编辑弹框支持搜索并选择已有目录，或点击路径框右侧的 folder 图标展开「自定义路径」，填写最多三级路径，再点击「使用此路径」回填，并预告待创建目录。标签直接在原标签区域内输入，按 Enter 自定义添加；仅在输入时显示最多 5 个匹配的已有标签，不展示全量推荐。卡片和弹框共用一组按显示顺序循环的浅色标签背景。仅点击「确认收藏」才将新目录及缺失父级与收藏记录一起持久化，取消不会创建。列表按目录层级显示，可展开与收起。任务可在任意状态刷新重新剪藏，保持任务位置和已有内容直至新结果生成。

## 数据

应用数据目录下的 `clips.json` 是统一的剪藏记录文件，包含 `tasks`（收藏元信息与任务状态）和 `categories`（目录路径集合）；不在「我的资料库」下建立目录或生成文章文件。兼容保留旧记录的正文和笔记字段；空字段不额外写入。新增 `draft` 保存未确认的编辑结果。

全局模型配置保存在同目录的 `model.json`。兼容读取之前的 `clip-ai.json` 和钥匙串密钥，下一次在设置页保存时使用新文件。

旧数组格式会自动升级，旧版未经过严格 AI 整理的待确认任务会重新排队，已归档收藏保留。目录在删除收藏后仍保留。

任务使用串行后台队列，离开页面继续工作；应用重启会恢复未完成任务。取消、删除和重试使用 revision 防止迟到结果覆盖记录。数据修改通过临时文件原子替换，损坏记录不自动覆盖。

浏览器预览只展示界面，真实任务和配置保存需在桌面应用执行。

模型密钥保存后会读回校验，当前进程缓存已成功读取的密钥，减少重复钥匙串读取。系统拒绝访问时显示恢复说明；设置 → 模型配置中编辑现有模型并重新填写 API Key，可重新测试、保存并校验密钥，不必删除模型。API Key 不写入剪藏或模型 JSON 文件。
