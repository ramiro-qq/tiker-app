# 资料库与文档交互

参考飞书的目录树、最近访问、收藏和自动保存规则；本应用当前是单机资料管理，不包含云端协作与权限系统。

| 功能 | 作用与交互 | 当前实现 |
| --- | --- | --- |
| 网页剪藏 | 主导航第二个入口，位于搜索之后，进入剪藏工作区 | 已调整顺序 |
| 最近文件 | 按最后打开时间排列；点击打开对应文件 | 真实列表，首次使用显示空状态 |
| 我的收藏 | 显示已收藏文件或文件夹；可取消收藏 | 与树、文档收藏按钮同步 |
| 根目录新建 | 文件夹标题旁的 + → 选择文档或文件夹 → 输入名称 | 新节点 parentId 为空 |
| 文件夹内新建 | 目录旁的 + → 选择类型 → 输入名称 | 保存到该文件夹并展开父目录 |
| 目录树 | 每个目录独立折叠，递归缩进；文件点击仅替换右侧 | 支持上下方向键导航、左右展开折叠、Home/End |
| 重命名 | 更多菜单 → 输入名称 | 同步树、列表及文档标题；同级重名自动加后缀 |
| 移动 | 更多菜单 → 选择目标文件夹或根目录 | 保留子树，禁止移动到自身或后代；同级重名自动加后缀 |
| 删除与撤销 | 确认删除，文件夹包含子树；提示条可撤销最近一次删除 | 撤销只恢复删除节点，不覆盖后续其他编辑 |
| 文档编辑 | 点击正文直接输入，标题直接改名；无需切换编辑/阅读态 | 富文本格式、链接、列表、引用、目录导航、行内标签、复制、导出 |
| 保存 | 修改自动保存，切换文件、刷新后可恢复 | 当前使用本机 WebView/browser localStorage；不是磁盘文件同步或云端保存 |
| PDF / 图片 | 只读展示，不显示文档编辑工具栏 | 使用独立附件预览模块；不进入富文本文档编辑 |
| Excel | 交给独立附件预览模块处理，不作为富文本文档编辑 | 本轮不包含原生 Excel 编辑引擎及保真回写 |

创建菜单只提供已接通的文档、文件夹，不提供无后续能力的类型按钮。去掉冗余的“我的空间 / 类型”Header，保留文档操作栏及其下分割线；格式工具仅在选中文字时浮出。操作栏实时展示正文字符数（不计标题与空白），不提供资料目录折叠按钮。侧栏移除搜索、冗余“资料”标题和附件导入入口及其专属导入逻辑。

尚未接通的能力：多人协作、权限分享、原生 Office 引擎、磁盘文件读写同步、真正的文档版本历史。原有全局搜索、标签与 Git 历史工作区仍独立，尚未改为基于新文件树的统一索引。
