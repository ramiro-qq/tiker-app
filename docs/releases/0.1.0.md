## 发行边界

本次未构建或发布新的桌面安装包，未进行真实账号 OAuth、模型服务、同步上传、Windows / Linux / Intel 设备验收。流水线仅配置，未在 GitHub Actions 实际运行。没有宣称正式签名、公证、自动更新或跨平台发行通过。

发布安装包前需要在此补充冻结 commit SHA、平台/架构、附件名、SHA256、签名/公证、实际安装升级测试及已知限制。当前不提供虚构下载链接或校验值；源码整理提交可从 Git 历史追溯。

## 数据与恢复

模型密钥、同步 Token、个人资料及本地运行文件不进入源码提交。业务内容同步由用户独立启用，不受源码忽略规则控制。升级前退出应用，按 [存储布局](../storage-layout.md) 备份资料库、配置及原附件。回退程序时应使用对应版本备份，不能假设旧版本能读取所有新数据。
